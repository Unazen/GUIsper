# Whisper Local GUI

GUI для уже установленного OpenAI Whisper.

Ожидается:
    ~/whisper/.venv/bin/python
    ~/whisper/.venv/bin/whisper

Установка:
    ./install.sh

После установки приложение появится в меню GNOME как "Whisper Local".

GUI НЕ устанавливает второй Whisper. Он использует существующий:
    ~/whisper/.venv/bin/python

Функции:
- выбор аудио/видео;
- модели tiny/base/small;
- выбор языка;
- TXT/SRT/VTT/TSV/JSON;
- выбор выходного файла;
- лог;
- распознавание в отдельном потоке, чтобы окно не зависало.

Интернет во время распознавания не используется. Если выбранная модель ещё не скачана, Whisper сам попытается загрузить её при первом запуске.
